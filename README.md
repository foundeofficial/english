# KoreBridge (코어브릿지) v2.0 — 30일 완성 하이브리드 영어교육 웹앱

한국인 학습자를 위해 **듀오링고·스픽 스타일의 7분 집중 스프린트**와 **기존 인강·유튜브·독해·A4 학습지/시험지·1:1 과외**를 하나로 통합한 1개월(30일) 완성 영어 학습 플랫폼입니다.

- **라이브 데모 (GitHub Pages)**: https://foundeofficial.github.io/english/

## v2.0 주요 기능

### 1. CEFR 6단계 정밀 레벨 시스템 (`Lv.1 입문 A1` ~ `Lv.6 마스터 C2`)
- 첫 방문 시 **1분 6단계 CEFR 진단 테스트**로 내 레벨을 자동 추천하며, 상단 설정에서 언제든 레벨과 하루 페이스를 변경할 수 있습니다.
- 모든 단원(Day 01–30)에 **6단계 레벨별 목표 문장 사다리(A1 → C2)** 와 레벨별 기본 재생 속도(0.85x–1.12x)가 연동됩니다.

### 2. 1개월(30일 · 5주) 전체 커리큘럼 & 하루 50분 풀코스 밀도
- **Week 1 (Day 01–06 · A1–A2)**: 일상 동선·의도 반전·일정 조율·마감 전치사(`by` vs `until`)·3문장 확장 + 1주차 종합평가
- **Week 2 (Day 07–12 · A2–B1)**: 카페/식당 커스텀 주문·공항 환승·호텔/교통·쇼핑 교환/환불·스몰토크 + 2주차 종합평가
- **Week 3 (Day 13–18 · B1–B2)**: 글로벌 화상미팅·영문 이메일·업무 보고/병목·회의 발언/완곡한 반론·피드백/거절 + 3주차 종합평가
- **Week 4 (Day 19–24 · B2–C1)**: 영어 프레젠테이션·윈윈 협상·가정법 리스크 시뮬레이션·STAR 영어 면접·격식↔구동사 전환 + 4주차 종합평가
- **Week 5 (Day 25–30 · C1–C2)**: BBC 스타일 AI/번아웃/문화 시사 토론·전술적 공감(TED)·고속 스피치/논설 에세이 + **Day 30 파이널 졸업 모의고사**
- **총 콘텐츠 규모**:
  - 필수 단어·구동사·연어 **450개** (매일 15개)
  - 검증된 무료 **유튜브 영어 교육 영상 40편** (Day별 30편 + 레벨별 보너스 10편 + 사용자 URL 불러오기)
  - 데일리 **영자 독해 지문 30편 + 이해도 퀴즈 90문항** (S/V/O 끊어읽기 + 해석 토글 + TTS)
  - 시트콤 대화 **180+ 턴** & 원리 칠판 강의 **90강**
  - 능동 스피킹/어순 스프린트 **300문항**
  - A4 단원평가 시험지 **475문항 + 쌍둥이 오답 클리닉 475문항 = 950문항**

### 3. 무료 외부 API 연동 실시간 영한·영영 사전 (`KoreBridge 스마트 영어사전`)
- 상단 **`영한사전` 버튼(단축키 `/`)** 또는 지문·대화·개념서의 **영어 단어 클릭**으로 즉시 열립니다.
- **무료·무인증 CORS API + 30일 코스 450단어 사전** 결합:
  - **Free Dictionary API** (`api.dictionaryapi.dev`): 발음기호(IPA), 실제 미국/영국 원어민 MP3 오디오, 품사별 영영 풀이·예문·유의어
  - **한국어 위키낱말사전 API** (`ko.wiktionary.org`): 실시간 한국어 뜻·한영 예문
  - **영어 위키낱말사전 OpenSearch API** (`en.wiktionary.org`): 실시간 영단어 자동완성 추천
- 검색한 단어를 원클릭으로 **내 사전 저장 단어장** 또는 **에빙하우스 오답 복습함(D+1)**에 저장할 수 있습니다.

### 4. 유튜브 실전 인강 스튜디오 (`YouTubeStudyPlayer`)
- 30개 단원 각각에 주제·레벨에 맞는 **임베드 검증 완료 유튜브 영어 강의**를 탑재했습니다.
- 핵심 타임스탬프 챕터 점프, 학습 미션 체크리스트, 나란히 보는 강의 필기장, 레벨별 40편 영상 라이브러리, 그리고 **원하는 유튜브 URL을 붙여넣어 바로 공부하는 커스텀 영상 학습기**를 지원합니다.

## 로컬 실행 방법 (Node 22 이상 권장)

```bash
git clone https://github.com/foundeofficial/english.git
cd english
npm install
npm run dev        # 브라우저에서 http://localhost:5173 접속
```

선택적으로 SQLite 영구 저장 서버를 함께 실행할 수 있습니다:
```bash
npm run server     # http://localhost:4000 (data/korebridge.sqlite)
```

## 검증 스크립트

```bash
npm run verify:curriculum   # 30일 전체 커리큘럼·시험지·쌍둥이 클리닉·독해·유튜브 QA 검증
npm run lint                # oxlint 정적 분석
npm run build               # TypeScript 컴파일 + Vite 코드 스플리팅 프로덕션 빌드
```
