# KoreBridge (코어브릿지) v3.0 — 30일 완성 하이브리드 영어교육 아카데미

한국인 학습자가 매일 **출퇴근길 7분 스프린트·자동재생**부터 **책상 앞 50분 유튜브 A–B 쉐도잉·딕테이션·영자 독해·A4 시험지·1:1 과외**까지 실제로 영어 실력을 끌어올릴 수 있도록 설계한 1개월(30일) 완성 영어 학습 플랫폼입니다.

- **라이브 데모 (GitHub Pages)**: https://foundeofficial.github.io/english/

## v3.0 핵심 학습 기능

### 1. 유튜브 프로 쉐도잉 스튜디오 (`YouTubeStudyPlayer`)
- 30개 단원별 맞춤 검증 영상 + 레벨별 보너스 10편 = **총 40편 무료 교육 영상** 탑재 + **내 유튜브 링크 직접 불러오기**
- **YouTube IFrame Player API 연동**: 끊김 없는 챕터 점프, **`-5초` / `+5초` 미세 이동**, **`A–B 구간 반복` 쉐도잉 루프**, **배속 조절(`0.75x–1.25x`)**, **현재 재생 시점 `[MM:SS]` 타임스탬프 필기 삽입**

### 2. 실시간 쉐도잉 발음 채점 & 블라인드 딕테이션 랩 (`ShadowingDictationLab`)
- 30일 전체 200턴 대화를 대상으로 **실시간 음성인식 발음 정확도 채점** + **`MediaRecorder` 내 목소리 녹음 & 원어민 비교 재생**
- **블라인드 받아쓰기(딕테이션)**: 원어민 음성을 듣고 받아적으면 축약형(`I'll` ↔ `I will`)을 공정하게 인정하면서 **단어별 일치/근접/누락(초록·노랑·빨강) 정밀 진단**과 약한 기능어(관사·전치사) 코칭 피드백 제공

### 3. 출퇴근 핸즈프리 귀트임 자동재생 (`CommuteAudioPlayer`)
- Day별 15단어, 내 영한사전 저장 단어장, 오답 복습함을 **영어 반복(1~3회) → 따라 말하기 텀 → 한국어 뜻 → 실전 예문** 순서로 자동 재생
- **미국식(US) · 영국식(UK) · 호주식(AU)** 3대 원어민 억양 전환 지원

### 4. CEFR 6단계 레벨 체계 & 1개월(30일) 통합 커리큘럼
- `Lv.1 입문(A1)` ~ `Lv.6 마스터(C2)` 6단계 진단 테스트 및 전 단원 6단계 목표 문장 사다리
- 단어 **450개** · 유튜브 **40편** · 영자 독해 **30편(90문항)** · 시트콤 대화 **200턴** · 칠판 원리 **90강** · 스피킹 스프린트 **300문항** · A4 시험지 **475문항 + 쌍둥이 오답 클리닉 475문항(총 950문항)**
- 35+ 콩글리시 진단 규칙 & 19개 주제별 한국어 프리셋으로 확장된 로컬 1:1 3단 패러프레이징 엔진(선택 시 Gemini 2.5 Flash 연동)

### 5. 무료 외부 API 연동 실시간 영한·영영 사전 (`DictionaryDrawer`)
- 상단 `영한사전` 버튼(단축키 `/`) 또는 지문·대화·개념서의 **영어 단어 클릭**으로 즉시 조회
- **Free Dictionary API** (IPA, US/UK 원어민 MP3 오디오, 영영 풀이·유의어) + **한국어 위키낱말사전** + **영어 위키낱말사전 OpenSearch** + **30일 코스 450단어 자체 사전**

### 6. 성장 리포트 · 취약점 자동 클리닉 · JSON 백업 (`GrowthReportDashboard`)
- 실시간 **일일 집중 학습 타이머** & 목표 달성 바, **5대 영어 핵심 역량 분석**, **최근 7일 학습 시간 막대 그래프**
- 시험 오답에서 자동 집계되는 **취약 문법 태그 클리닉**, **30일 마스터리 현황표**, **JSON 백업/복원**, **A4 성적표 인쇄/PDF**

## 로컬 실행 & 검증

```bash
git clone https://github.com/foundeofficial/english.git
cd english
npm install
npm run dev                 # http://localhost:5173
npm run server              # 선택: SQLite 영구 저장 서버 (http://localhost:4000)

npm run verify:curriculum   # 30일 전체 커리큘럼·시험지·독해·유튜브 QA
npm run lint                # oxlint 정적 분석
npm run build               # TypeScript + Vite 코드 스플리팅 빌드
```
