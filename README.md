# KoreBridge (코어브릿지) — 한국인을 위한 하이브리드 영어교육 스튜디오

출퇴근길 **7분 어순 반사신경 스프린트(스픽·듀오링고·말해보카식)**와 책상 앞 **40분 시네마틱 인강 · 1:1 원어민 과외 · A4 단원평가 시험지(링글·리얼클래스·학원 시스템)**를 하나로 결합한 실전 영어 학습 웹 애플리케이션입니다.

## 핵심 구성 (성인 · 대학생 · 직장인 실전 회화 & 비즈니스 코어 트랙 — Week 1 풀 패키지)

1. **개인 맞춤형 레벨 · 학습 페이스 캘리브레이션**
   - 30초 미니 레벨 진단 테스트(`Lv.1 기초 코어` / `Lv.2 실전 표준` / `Lv.3 비즈니스 심화`) 및 하루 학습량(`7분` / `20분` / `45분`), `S/V/O 직독직해 끊어읽기(/)`, `지하철 묵음 모드` 실시간 전환
2. **오늘의 학습 & 7분 풀스크린 집중 스프린트**
   - 단원별 **10문항 능동 발화 드릴** (`어순 청크 조립`, `구동사·전치사 빈칸 타이핑`, `콩글리시 vs 원어민 판별`, 실시간 음성인식 & 오답 완전 정복 루프)
3. **시네마틱 인강 & 1:1 AI 원어민 과외**
   - **1교시 시트콤 스토리 영상 플레이어**: 고해상도 상황 일러스트 + Ken Burns 카메라 워크 + 화자별 멀티 보이스 TTS 연속 재생 + 한/영/무자막 전환 + 클릭형 대본
   - **2교시 원리 칠판 강의 & 필기장**: 한국인이 가장 자주 틀리는 어순·전치사·콩글리시 원리 3강 및 격식별(`Casual / Standard / Formal`) 온도차 스펙트럼
   - **3교시 1:1 원어민 롤플레이 & 3단 패러프레이징**: 링글식 `① 문법·콩글리시 교정` → `② 친한 동료 캐주얼 표현` → `③ 글로벌 비즈니스 격식 표현` 첨삭 (선택적으로 `Google Gemini 2.5 Flash API Key` 입력 시 실시간 LLM 첨삭 연동)
4. **단원 개념 원리서 & 실전 A4 단원평가 시험지 (`🖨️ 인쇄/PDF 지원`)**
   - Day 01~05 각 **15문항** + Day 06 주간 종합 모의고사 **20문항** (총 **95문항 본시험 + 95문항 쌍둥이 변형 오답 클리닉 = 190문항**)
   - 자동 채점 및 빨간색 성적 스탬프 발급, 틀린 문항 즉시 **쌍둥이 변형 문제 클리닉** 제공
5. **15단어 셀로판지 암기장 · 팝퀴즈 · 에빙하우스 오답 복습함**
   - Day별 엄선 **15개 핵심 구동사·연어**(Week 1 총 **90개 어휘**), 한국어 뜻/영단어 셀로판지 가림막, 15문항 예문 스펠링 팝퀴즈, `D+1 → D+3 → D+7 → D+14 → D+30` 망각곡선 복습 덱

## 로컬 PC 실행 및 배포 방법

### 1. 프론트엔드 단독 실행 (권장 · 별도 서버 없이 100% 작동)
브라우저 `localStorage`와 내장 첨삭·채점 엔진으로 즉시 실행되며, Vercel · Netlify · Cloudflare Pages 정적 배포와도 100% 호환됩니다.

```bash
git clone https://github.com/foundeofficial/english.git
cd english
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

### 2. 커리큘럼 무결성 QA 검증 & 프로덕션 빌드

```bash
# 90개 어휘 · 60개 스프린트 · 190개 본문항+쌍둥이 문항 무결성 자동 검증
npm run verify:curriculum

# 린트 및 프로덕션 번들 빌드 (dist/ 생성)
npm run lint
npm run build
```

### 3. 선택형 Node.js 내장 SQLite API 서버 함께 실행 (Node 22.5+)

```bash
npm run server
```
